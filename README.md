# BuyerScan
<img src="https://i.ibb.co/zWZMb5tp/213.jpg" alt="Превью проекта" width="100%">

BuyerScan — это специализированный мобильный AI-сервис (PWA-терминал), спроектированный для полевых условий работы оптовых рынков и складов. 

Закупщик наводит камеру смартфона на образец товара и вводит закупочную цену поставщика
Сервис находит аналоги на маркетплейсах, рассчитывает чистую юнит-экономику с учетом скрытых тарифов площадки и выносит вердикт 
Позволяет сохранить позицию в смету партии и сгенерировать готовый SEO-пакет атрибутов карточки через LLM.
Быстрый анализ по рынку позволяет посчитать точную прибыль с учетом тарифов и реальных цен, а также генерировать готовые карточки товаров и SEO описаний. Тем самым экономя средства на финансовых аналитиков и ускоряя цикл вывода товара в оборот без найма контент-агенств.
